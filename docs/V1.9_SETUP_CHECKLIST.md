# V1.9 部署检查清单

1. Supabase SQL Editor 执行 `supabase/schema.sql`
2. Vercel 环境变量：
   - NEXT_PUBLIC_SUPABASE_URL
   - NEXT_PUBLIC_SUPABASE_ANON_KEY
   - SUPABASE_SERVICE_ROLE_KEY
   - OPENAI_API_KEY
   - OPENAI_TEXT_MODEL
   - SYNC_API_TOKEN
   - SYNC_USER_ID
3. 部署后登录网站一次
4. 首页执行“导入我的历史学习资料”
5. 修改 `docs/chatgpt-action-openapi.yaml` 中的域名
6. 创建/配置一个自定义 GPT Action
7. Action 认证选择 Bearer API Key，值为 `SYNC_API_TOKEN`
8. 在 ChatGPT 中完成一次测试练习并说“结束并同步”
9. 网站首页确认出现“待审核练习”
10. 批准后确认错误/语法/语料进入资料库与复习队列
